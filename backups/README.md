# Резервные копии выпусков

В каждом каталоге `vX.Y.Z` сохранены оригинальный Windows-архив, его контрольная сумма SHA-256 и `manifest.json`. Внутри ZIP находятся EXE и исходники соответствующей версии. Все пять первых выпусков восстановлены из ранее подготовленных архивов без изменения их содержимого:

- [v1.0.0](v1.0.0/)
- [v1.1.0](v1.1.0/)
- [v1.1.1](v1.1.1/)
- [v1.2.0](v1.2.0/)
- [v1.3.0](v1.3.0/)

Исходный код каждого выпуска доступен также по одноимённой Git-метке. Даты коммитов восстановления не являются датами первоначальной разработки.

Архивы и метки нельзя заменять: исправленная программа получает новый номер версии. Скрипт `scripts/backup_version.py` проверяет существующий архив и отказывается его перезаписывать. Исходные ZIP новых версий исключают папку `backups`, чтобы не вкладывать старые архивы в каждый новый.

Проверка контрольной суммы из каталога конкретной версии в Linux: `sha256sum -c SHA256SUMS.txt`. В PowerShell: `Get-FileHash .\имя_архива.zip -Algorithm SHA256`; сравните результат с `SHA256SUMS.txt`.
