# Strata Draw для CorelDRAW 2025

Бесплатная панель для геологических разрезов, карт и каротажных планшетов. Работает внутри установленного CorelDRAW 2025 для Windows x64. Операции с чертежом и встроенные библиотеки работают локально. Код панели распространяется по MIT. Источники и лицензии справочных данных перечислены в [data/SOURCES.md](data/SOURCES.md).

## Установка

Скачайте [установщик Strata Draw для Windows x64](downloads/StrataDraw-Setup-CorelDRAW2025-x64.exe). Сохраните чертежи, закройте CorelDRAW и запустите EXE. Подтвердите запрос Windows на права администратора и проверьте показанную папку. Установщик найдёт CorelDRAW 2025 по регистрации Windows или каталогу установки. Если потребуется выбор, укажите файл CorelDRW.exe вашей версии 2025.

EXE содержит панель, каталоги и зависимости для автономной установки. Он также обновляет ранее установленную версию Strata Draw. Требуются установленный CorelDRAW 2025 x64 и .NET Framework 4.8 или новее. Установщик распространяется без цифровой подписи.

### Ручная установка из ZIP

1. Скачайте [ZIP для CorelDRAW 2025](downloads/StrataDraw-CorelDRAW2025.zip) и распакуйте его.
2. Закройте CorelDRAW. Скопируйте папку **StrataDraw целиком**, включая подпапку **data** и все DLL, в каталог **Programs64/Addons** вашей установки CorelDRAW 2025. Для установки под Program Files могут потребоваться права администратора.
3. Откройте CorelDRAW и создайте документ. Найдите команду **Strata Draw** в меню приложения. Выберите инструмент в верхней части панели. Поле внизу задаёт слой результата, пустое поле означает активный слой.

При обновлении замените файлы предыдущей сборки StrataDraw из этого же проекта. Персональные настройки находятся в `%LOCALAPPDATA%\StrataDraw\settings.xml`.

## Инструменты

| Инструмент | Как работать |
| --- | --- |
| Прослои | Выделите кровлю и подошву или замкнутый контур. Выберите породу, расстояние или число прослоев, знаки и частоту. Настраиваются смещение рядов, дополнительные знаки, их размер, поворот и случайное размещение. Для собственного знака можно открыть SVG, CGM или CDR. |
| Векторный узор | Выделите контур или две границы. Найдите плитку по номеру или названию, укажите ширину и поворот. Есть 471 плитка FGDC и 10 штриховок открытого базового профиля 2013 года. Можно добавлять свои файлы SVG, CGM, CDR и узоры Corel PAT. Кнопка «Указать на чертеже» выбирает ограниченную область по точке. |
| Возраст | Выберите интервал по русскому или английскому названию. Заливка и индекс наносятся по выделению или щелчку. Встроена международная шкала ICS 2024/12 из 171 интервала с цветами CGMW. Другие шкалы можно добавить из XML с элементами `unit` и атрибутами `name`, `index`, `color`, `from`, `to` и `level`. С точным видом таблицы ВСЕГЕИ работает подключение соответствующего XML. |
| Линия | Выберите кривую. В каталоге 8 базовых стилей и 43 стиля FGDC. Доступны сплошная, пунктирная, волнистая и пилообразная линии, группы знаков, параллельная линия, обратное направление и произвольный ритм штрихов. Исходная кривая сохраняется в документе. Для возврата выделите созданную линию и нажмите «Вернуть исходную кривую». |
| Знак | Найдите один из 716 точечных знаков или добавьте собственный. Задайте высоту и угол. Вставьте знак по щелчку либо в центр выделенной фигуры. |
| Горизонты | Откройте таблицу с X в первом столбце и отметками горизонтов в остальных. Поддерживаются запятые, точки с запятой, табуляция, пробелы и фиксированная ширина полей. Задайте единицы, масштабы по осям, рамку, подписи и отступ от угла листа. Результат можно вставить в документ или сохранить в SVG. |
| Каротаж LAS | Откройте текстовый LAS с глубиной в первом столбце. Выберите кривые, масштабы, ширину дорожек, шаг сетки и допуск упрощения. Поддерживаются многострочные записи WRAP, пропуски NULL, логарифмические и обратные шкалы, цветная заливка и несколько кривых на дорожке. |
| Легенда | После оформления страницы нажмите «Построить легенду». Панель собирает использованные объекты Strata Draw по их метаданным. Можно ограничиться выделением, разбить легенду на разделы и колонки, изменить размер плашек и отсортировать возрасты от молодых к древним. |

Внизу инструмента можно сохранить несколько именованных наборов параметров. Панель запоминает последнюю вкладку и введённые значения. Для сложной группы на линии задайте по одной строке на знак, например `Triangle;2;1;верх;2` — треугольник шириной 2 мм и высотой 1 мм над линией в каждой второй группе.

Для каротажа строка `1;1;1;100;log;#175779;0.3;1` помещает первую кривую на первую дорожку, задаёт логарифмическую шкалу от 1 до 100, толщину 0,3 мм и заливку. Декоративные элементы чертежа настраиваются до построения.

## Проверки и совместимость

В Linux собирается WPF-библиотека под .NET Framework 4.8 и выполняются тесты вычислительного ядра. Они охватывают замкнутые области с отверстиями, пересечения границ, противоположные направления горизонтов, обрезку прослоев, оформление линий, импорт LAS и таблиц, справочники и разбор регистрационных XSLT.

Для проверки интеграции на Windows в ZIP включён Check-Corel.ps1. Из папки распакованного архива запустите в 64-разрядной Windows PowerShell:

```powershell
powershell.exe -STA -File .\Check-Corel.ps1
```

Скрипт обращается к CorelDRAW 2025 через COM, создаёт новый несохранённый документ и выполняет построения. Успешный запуск печатает PASS. Отдельно проверьте открытие панели из меню и инструмент выбора области по щелчку. Проверка в установленном CorelDRAW 2025 при подготовке этой сборки ещё не выполнена.

## Сопоставление с Lithology Docker 5

Состав инструментов сопоставлен с описанием версии 5 на [странице проекта](https://sourceforge.net/projects/litholo-docker/files/). На странице [Documentation](https://sourceforge.net/projects/litholo-docker/files/Documentation/) опубликованы ссылки на ГОСТ 21.302-2021, ГОСТ 2.857-75 и шкалу И. А. Зинченко. Полная библиотека обозначений двух ГОСТов, все предустановленные стили исходной программы и точное совпадение оформления её планшетов остаются непроверенными. Встроенный базовый профиль 2013 года атрибутирован отдельно. Панель использует собственный код и открытые графические библиотеки.

## Сборка

Из корня репозитория в Linux x86-64 запустите:

```bash
bash scripts/setup.sh
bash scripts/check.sh
```

Установщик проверяет SHA-512 SDK .NET 10.0.404 и восстанавливает закреплённые зависимости. Скрипт проверки создаёт установочный EXE и оба ZIP-файла в artifacts, а также образцы SVG для разреза и каротажа в artifacts/samples. Первый запуск требует доступа к builds.dotnet.microsoft.com и api.nuget.org.
