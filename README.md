# Strata Draw

Открытая панель для литологических чертежей в CorelDRAW 2025 под Windows. Код и авторские рисунки распространяются по лицензии MIT. Для работы панели потребуется установленный CorelDRAW. Ядро, которое строит SVG, работает и в Linux.

## Первая сборка

Панель генерирует редактируемый векторный образец размером 48 × 24 мм. Доступны песок, глинистый сланец и известняк. Пользователь выбирает шаг рядов от 2 до 8 мм. Геометрия состоит из окружностей и отрезков. Кнопка вставки передаёт SVG фильтру импорта активного слоя через API CorelDRAW. Применение заливки внутри произвольного выделенного контура — следующий отдельный этап.

## Среда разработки

Распакуйте StrataDraw-project.zip или откройте репозиторий, созданный из папки strata-draw. Работайте в существующей копии проекта. Для облачной машины подходит Linux x86-64 с Bash, curl, tar, sha512sum, Python 3 и библиотеками среды выполнения .NET, включая ICU и OpenSSL. Установщик скачивает официальный SDK .NET 10.0.404, проверяет SHA-512 и восстанавливает эталонные сборки .NET Framework 4.8 по пакетным lock-файлам. Интернет нужен для первого запуска. Используются builds.dotnet.microsoft.com и api.nuget.org. .env содержит локальные инструменты и кэш зависимостей.

В поле скрипта установки новой облачной среды используйте следующие команды, указав фактический путь рабочей копии:

```bash
cd /workspace/strata-draw
bash scripts/setup.sh
```

В инструкции запуска новой среды укажите:

```bash
cd /workspace/strata-draw
bash scripts/check.sh
```

Скрипт собирает библиотеку WPF, проверяет геометрию и формирует три примера в artifacts/samples. В artifacts также будут два ZIP-файла с исходниками и с панелью для Windows. Облачные проверки работают без CorelDRAW. Для работы с dotnet из той же оболочки выполните `source scripts/activate.sh`.

## Проверка в CorelDRAW 2025

1. Закройте CorelDRAW. Из архива StrataDraw-CorelDRAW2025.zip скопируйте папку StrataDraw в каталог Programs64/Addons установленной версии CorelDRAW. Внутри Programs64/Addons/StrataDraw должны находиться StrataDraw.dll, CorelDrw.addon, AppUI.xslt и UserUI.xslt.
2. Запустите CorelDRAW 2025, создайте пустой документ с доступным для редактирования слоем и найдите команду Strata Draw в меню приложения. Для проверки интеграции убедитесь, что она открывает панель.
3. Выберите породу и шаг и вставьте образец. Проверьте размеры, возможность редактирования и повторную вставку с другим шагом. Исходные образцы для визуального сравнения получаются командой проверки в Linux.
4. Для удаления закройте CorelDRAW и удалите установленную папку StrataDraw.

## Объём дальнейшей разработки

| Возможность | Состояние |
| --- | --- |
| Создание образцов | Генератор трёх авторских рисунков и облачные тесты готовы. Загрузка панели, импорт и физические размеры в CorelDRAW требуют проверки на Windows. |
| Заливка выбранного объекта | Предстоит реализовать привязку к контуру с учётом отверстий, поворота и масштаба. |
| Каталог обозначений | Предстоит создать библиотеку литологических символов и проверить обозначения по применимым стандартам ГОСТ и FGDC. |
| Геологические линии | Предстоит реализовать размещение знаков вдоль кривой, частоту и ориентацию. |
| Геохронологическая шкала | Предстоит определить набор шкал, источники данных и условия их использования. |
| Интерактивное применение | Предстоит реализовать нанесение выбранного оформления на объекты документа. |

Файл сопоставления функций — русское руководство, приложенное к дистрибутиву с именем 5.0.0.18. Внутри документа указана версия 3.8.4.0. Точный набор дополнений версии 5.0.0.18 предстоит уточнить по документации этой версии или рабочим примерам.
