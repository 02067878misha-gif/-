# Сетка Вульфа — генератор заданий

Автономная программа для Windows 10/11 x64. Подбирает от 1 до 20 разных вариантов, создаёт задания и отдельные ответы преподавателя в PDF. Интерфейс на русском открывается в установленном браузере. Интернет, Python, Microsoft Office и установка программы не нужны.

## Запуск готовой программы

1. Распакуйте `WulffGenerator_Windows_x64.zip` в обычную папку.
2. Запустите `WulffGenerator.exe`. Откроется локальный интерфейс в браузере.
3. Выберите количество вариантов, виды заданий и режим: прямые, обратные либо оба.
4. Нажмите **«Создать комплект PDF»** и скачайте файлы по появившимся ссылкам. Браузер сохраняет их в свою папку загрузок или предлагает выбрать папку, согласно своим настройкам.
5. Завершайте работу кнопкой **«Закрыть программу»**. После закрытия вкладки без этой кнопки процесс завершится через 15 минут без активности.

На компьютере должна быть настроена программа браузера по умолчанию. Программа запускает только локальный HTTP-сервис на `127.0.0.1` со случайным портом и кодом доступа, не обращается к внешним серверам и не отправляет данные в интернет. При каждом запуске используется новый адрес. Файл EXE собран без цифровой подписи.

## Что входит в комплект

| Файл | Назначение |
|---|---|
| `students.pdf` | Задания студентам: численные условия прямых задач, готовые построения обратных задач, сетки и место для ответов |
| `teacher.pdf` | Те же варианты с правильными построениями и численными ответами |
| `answers.csv` | Краткий ключ для Excel, UTF-8 с BOM, разделитель `;` |
| `settings.json` | Параметры генерации и полные расчётные ответы |
| `PRINT_README.txt` | Правила печати и условные обозначения |
| `wulff-set.zip` | Весь комплект одним архивом |

Студентам выдавайте только `students.pdf`. Таблица, JSON и файл преподавателя содержат ответы.

По два задания на странице, диаметр сетки **100 мм**. Печать: **A4 → фактический размер / 100%**, без подгонки. Проверьте диаметр линейкой после печати. Все страницы каждого варианта идут подряд; номер варианта напечатан на каждой странице. Все четыре типа заданий в обоих направлениях дают **4 страницы на вариант**, то есть **80 страниц в каждом PDF** для 20 вариантов. Состав можно сократить в интерфейсе; число страниц пересчитывается заранее. Комплект `examples/` содержит два демонстрационных варианта.

## Типы заданий

- **Плоскость**: построение дуги и полюса по азимуту и углу падения; обратное определение залегания по дуге.
- **Линейный элемент**: нанесение точки по азимуту и углу погружения; обратное считывание.
- **Линейность в плоскости (rake)**: построение по плоскости и rake, определение погружения; обратное определение плоскости, линии и rake.
- **Крылья складки**: построение двух крыльев, определение шарнира, двух двугранных углов и двух биссекторных плоскостей. В обратной задаче крылья уже нанесены.

Выбор соответствует видам элементов из приложенных презентации и таблицы. Исходные строки Excel не копируются: программа генерирует новые значения. Шаг исходных углов — 1°, 5° или 10°. Падения плоскостей выбираются в пределах 15–75°, погружения отдельных линий — 10–70°, rake — 15–75°, с округлением диапазона к выбранному шагу. Для складок отбираются пары с острым двугранным углом 25–80° и погружением шарнира не более 65°. Так исключаются вырожденные и трудночитаемые случаи. Каждый выбранный тип задания отличается между вариантами.

## Геометрические соглашения

Используется приложенная пользователем `Wulff10sm.bmp`, встроенная как PNG без изменения геометрии. Проекция **стереографическая равноугольная (Вульфа)**, нижняя полусфера. Север сверху, восток справа; азимуты отсчитываются от севера по часовой стрелке. Азимут плоскости — **азимут падения**, линии — **азимут погружения**.

Rake отсчитывается в плоскости от направления простирания **(азимут падения − 90°)** к линии падения, 0–90°. Это соглашение указано в заданиях. Все элементы строятся аналитически в одной системе координат: восток, север, вниз. Радиус стереографической проекции линии `r = tan(45° − plunge/2)`.

По двум неориентированным плоскостям нельзя однозначно выбрать внутренний угол складки и осевую поверхность. Поэтому программа даёт **острый угол и его дополнение до 180°**, а также **обе биссекторные плоскости A и B**. Для выбора геологической осевой поверхности нужны сведения о полярности/внутренней области складки. Это геометрическая модель симметричной складки, а не восстановление произвольной природной осевой поверхности.

Ответы в PDF и CSV округлены до 0,1°, исходные параметры и неокруглённые вычисления записаны в JSON. Для ручного считывания ориентир допуска — ±2°; окончательный допуск устанавливает преподаватель. Азимуты 0° и 360° эквивалентны. Для горизонтальной оси допустимы противоположные направления.

## Повторение набора

Введите тот же **код набора**, выберите те же типы заданий, шаг, режим и количество в версии алгоритма `wulff-v1`. При увеличении количества первые варианты сохраняются. Пустой код автоматически создаёт новый набор при каждом нажатии кнопки. Код готового набора отображается рядом со ссылками и записан в PDF и JSON. `settings.json` предназначен для чтения параметров, автоматического импорта в интерфейсе нет.

## Сборка из исходников

Нужен официальный Go 1.24 или новее; использован Go 1.27.3. Один модуль PDF, зафиксированный в `go.mod` и `go.sum`. Шрифт, сетка и веб-интерфейс встраиваются внутрь EXE.

```sh
go mod download
go test ./...
go vet ./...
go build -o wulff .
./wulff
```

Windows x64 из Linux:

```sh
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags='-s -w -H=windowsgui' -o dist/WulffGenerator.exe .
```

В PowerShell из папки исходников:

```powershell
$env:GOOS = 'windows'
$env:GOARCH = 'amd64'
$env:CGO_ENABLED = '0'
go test ./...
go build -trimpath -ldflags '-s -w -H=windowsgui' -o dist/WulffGenerator.exe .
```

Генерация без интерфейса (из Linux либо через `go run .`):

```sh
./wulff --generate --count 20 --seed GEO-2026 --step 5 --mode both --tasks plane,line,rake,fold --out output
```

Папка вывода не должна содержать файлы предыдущего комплекта: CLI сохраняет их, завершаясь с ошибкой, вместо перезаписи. Для сохранения следующего набора выберите другую папку.

## Проверки

В `geometry_test.go` есть аналитические эталоны проекции, полюсов, rake и симметричной складки, проверки принадлежности линий плоскостям и шарнира обоим крыльям, биссекторных плоскостей, повторяемости и уникальности наборов. В `server_test.go` проверяются генерация файлов, скачивание ZIP, число страниц по настройкам и обработка неверных запросов.

Проведены проверки программы в Linux, интерфейса в Chromium и печатного комплекта из 20 вариантов: A4, сетки 100 мм, 80 страниц в каждом PDF, отсутствие текста за пределами страницы. Windows EXE собран как PE32+ x86-64 GUI; запуск непосредственно в Windows в этой среде не проверен.
